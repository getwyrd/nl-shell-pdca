- NEEDS-HUMAN [impl] — **The prompt rule degrades healthy, common idioms that read a redirected fd 0.** At `src/nl_shell/session.py:702-711`, `_reading_terminal` treats any `read(0, …)` by bash as "back at a prompt". It never checks that fd 0 is still the PTY. Concrete cases, each run on a fresh session, all degrade after 1.1 s with "no done record after the shell returned to a prompt" and `result=None`:
  - `while read -r l; do echo got $l; done < <(sleep 2; echo hi)`
  - `read x < <(sleep 1.5; echo hi); echo $x`
  - `mapfile -t a < <(sleep 1.5; printf 'a\nb\n')`

  The command really did run, but the caller gets no status and no output and has to restart. This fails closed, so it is not a security hole. But it is wider than the limit the brief accepted (#136 covers only `read x` with no input). Suggested fix: count `read(0)` only when `/proc/<pid>/fd/0` resolves to this session's PTY slave. A missing `fd/0` would fail closed the same way a missing `syscall` file does. The fix also needs a (k)-style test with `< <(sleep 1.5; …)`.
- NEEDS-HUMAN [human] — **One confirmed command can turn off bracketed paste without degrading, and the next command then runs as raw keystrokes.** At `src/nl_shell/session.py:545`, `run()` always writes `PASTE_START + data + PASTE_END + "\r"`, but nothing checks that readline still has bracketed paste on. Reproduced case: `export TERM=dumb` (or `bind 'set enable-bracketed-paste off'`) is reported as ran and HEALTHY. Then `run("echo /etc/hostnam\tX; touch $HOME/MARK")` is written to the PTY and **runs** (MARK is created). Only after that does the session degrade with "output could not be delimited". With paste off, a TAB in the confirmed bytes triggers completion, so the line bash runs is not the confirmed line. That breaks §5, and brief decision 10 says "refuse, not confirm then run". The threat model's Known gaps (`.oss-scanner/threat_model.md:184`) already lists "readline state" for #141, which explains the `bind` case. `TERM` is an environment variable, though, not a readline binding. A human should confirm that #141's scope (or V) covers `TERM`, or decide this child should add `TERM` to H.

The code builds `f"{_quote(url)!r}"`. `_quote` turns an ESC byte into the four characters `\x1b`, and `!r` then doubles the backslash. So a URL such as `http://h\x1b` shows on stderr as `'http://h\\x1b'`. A URL that really contains a backslash, or the literal text `\x1b`, prints exactly the same, so the user cannot tell them apart. A URL containing `'` switches repr to double quotes. `_error` runs `render.escape` again on top. The output is still safe, because nothing hidden reaches the terminal, but the message does not show the URL accurately.

# Brief — issue 155 / failure-classifier-by-exit-code (child-1 of #62)

> Child of #62 (M0.12), split at Plan on 2026-10-19. **Re-planned a second time on
> 2026-10-21.** Rounds 1–3 failed because a hand-written bash *expander* never caught every
> spelling; rounds 4–5 failed because a hand-written *command-word scanner* (one that tracks
> quotes, `$(…)` nesting, `[[ ]]`, `case` arms and comments) kept drifting out of step with
> bash. The human decided at this re-plan: **replace all of that with a stateless rule**
> (option D below). It never tracks quotes or nesting, so there is no state to drift. Any gap
> left by this rule is followed up in #12 (the AST-based policy gate), not in this slice.
>
> **Do NOT reuse the scanner from iteration-v4/v5** (`_scan`, `_split`, `in_test`, frame
> stacks, comment handling, quoted-word re-split). No tokenizer is needed for the privilege
> check: it is regex and character-class tests over the raw text.
>
> Builds on ADR-0014 Decision 2 (exit codes are trusted only from the control channel's
> done record), ADR-0015 / ADR-0006 (never offer anything that touches the sudo password),
> ADR-0017 (only the reader sees raw untrusted text).

- **Slug:** failure-classifier-by-exit-code
- **Defect:** nl-shell has no deterministic first pass that classifies a failed command from trusted facts only (the `session.CommandResult` from the done record and the command text the user confirmed) before anything goes to a model. Add `src/nl_shell/failure_classes.py` with `classify(result, command, lookup=None)` returning a `Failure` with the class, a fixed message (no model), `offer_correction` and `to_reader`. Classes: none, interrupted (130), privilege, not-found (127, with an optional package suggestion from an injected lookup), not-executable (126), killed by signal n (129–192 except 130, named, with the OOM-killer hint for 137), other.

  **Rules** (decisions 1–4 of #62 confirmed 2026-10-19; the privilege rule replaced by the human on 2026-10-21). Text `T` is the confirmed command text.

  1. **Privileged** if any of P1–P5 holds for `T`:
     - **P1 literal name, anywhere:** take `T`, delete every backslash-newline pair, then delete every `\`, `'` and `"`. Privileged if the result contains one of the ten names where the character before it is not a letter, digit or `_` (or it is at the start), and the character after it is not a letter, digit, `_`, `.` or `-` (or it is at the end). The ten names: policy-gate spec §4 (`docs/design/specs/policy-gate/v1.md:111`) plus the `-rs` / `.ws` / `sudoedit` variants. Comments, quoted messages and here-doc bodies are matched too (accepted over-match).
     - **P2 code-running or quoting marker, anywhere:** `T` contains `$(`, a backtick, `<(`, `>(`, `$'`, `$"` or a backslash.
     - **P3 unclear first word of a segment:** cut `T` at every `;`, `&`, `|`, `(`, `)` and newline, ignoring quotes entirely. In each segment, split on whitespace and walk the pieces: skip these keywords: `if then else elif do while until ! time { coproc`; skip assignments (`NAME=…` or `NAME+=…`); skip a redirection piece (optional fd digits, then one of `<<< << >> <> >| >& <& &>> &> < >`), and if the piece is only the operator, skip the next piece too (its target). The first piece left is the segment's first word. It is **plain** if it is a bash builtin (`router.BASH_BUILTINS`), a bash keyword (the `compgen -k` list: `if then else elif fi case esac for select while until do done in function time { } ! [[ ]] coproc`), or it fully matches `(~/)?[A-Za-z0-9._+/-]+`. Not plain → privileged. Only the first word of each segment is checked.
     - **P4 function:** any piece of `T` (quote characters deleted, cut and split as in P3) equals a name in `snapshot.functions`.
     - **P5 alias:** any such piece equals an alias name in `snapshot.aliases` and the alias value is privileged by P1–P5 (follow chains; a cycle or a chain over 8 deep counts as privileged). Read each `alias NAME=VALUE` line; unquote `VALUE` with `shlex.split`, and if that raises, use `VALUE` as written.

     Accepted cost (human, 2026-10-21): no fix offer for any command that mentions a privilege name anywhere, contains any P2 marker, has a segment whose first word is not plain, or names one of the user's shell functions. That includes `echo $(date)`, `grep 'a\|b' f` and `git commit -m "fix: x (y)"`.
  2. **`ran=False`.** Blank text, or text whose every non-blank line starts with `#` after leading whitespace → none. Otherwise privileged text → privilege. Otherwise → other (a syntax error).
  3. **Input type.** Only `session.CommandResult`; anything else raises `TypeError`.
  4. **127 suggestion.** Only when `T` has none of `; & | ( ) < > $` backtick, backslash or newline, its first piece is not an assignment, and that first word did not resolve: not a snapshot alias, not a bash builtin or keyword (minus names in `snapshot.disabled_builtins`), not an executable file in any `snapshot.path` directory (an empty or `.` entry means "unknown": no suggestion). The first word may come from `router.first_token` (`src/nl_shell/router.py:38-48`). Lookup contract: `Callable[[str], Iterable[str]]`. A bare `str` result is one name; `None` or an exception means none. The classifier trusts the provider to have checked names (#156 does) and only applies display safety.

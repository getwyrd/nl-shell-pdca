So a command that points fd 4 at something else (`exec 4</dev/null`) degrades with `outside-check` and does not skip the check. A DEBUG trap that removes itself before `$3` is expanded still had to run before the read, so its `stty` change shows up at `session.py:865`. A trap that stays set shows up in `H` through `$3`/`$4`.
